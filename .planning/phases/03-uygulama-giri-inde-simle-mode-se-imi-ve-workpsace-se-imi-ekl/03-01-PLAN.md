# Phase 3: Simple Mode and Workspace Selection - Plan 1

## Goal
Introduce a startup mode selection screen allowing users to choose between an ephemeral "Simple Mode" and a persistent "Workspace Mode". Provide options to remember the choice and a header toggle to switch modes.

## Tasks

### 1. Create Application Mode Hook
<task>
<read_first>
- hooks/useAppMode.ts
</read_first>
<action>
Create `hooks/useAppMode.ts` that exports a hook `useAppMode`.
1. It should manage a state `mode` of type `'simple' | 'workspace' | null`.
2. On initial mount, it should check `localStorage.getItem('app_default_mode')`. If present, set `mode` to that value. Otherwise, keep it `null`.
3. Provide a function `selectMode(newMode: 'simple' | 'workspace', remember: boolean)` that sets the mode, and if `remember` is true, saves it to `localStorage`.
4. Provide a function `switchMode(newMode: 'simple' | 'workspace')` that just changes the mode (and removes the `app_default_mode` from `localStorage` if they manually switch, or updates it if we want to keep the new one as default - let's just clear the default if they manually switch so next time they are asked, OR just update the current session mode without changing the default).
</action>
<acceptance_criteria>
- `grep -n "export default function useAppMode" hooks/useAppMode.ts` returns > 0 lines.
- `grep -n "localStorage.getItem('app_default_mode')" hooks/useAppMode.ts` returns > 0 lines.
</acceptance_criteria>
</task>

### 2. Update Collections Hook for Ephemeral Mode
<task>
<read_first>
- hooks/useCollections.ts
</read_first>
<action>
Modify `useCollections.ts` to support Simple Mode:
1. Accept an argument: `isSimpleMode: boolean = false`.
2. If `isSimpleMode` is true, avoid loading from or saving to `localStorage`.
3. In `isSimpleMode`, initialize `collections` with a single default file (e.g., `id: 'default-1', name: 'untitled.json', type: 'file', content: '{}', parentId: null`). Set `selectedId` to this file.
4. When `isSimpleMode` changes, reset the collections state appropriately.
</action>
<acceptance_criteria>
- `grep -n "isSimpleMode" hooks/useCollections.ts` returns > 0 lines.
- `grep -n "untitled.json" hooks/useCollections.ts` returns > 0 lines.
</acceptance_criteria>
</task>

### 4. Integrate Mode Selection in Main View
<task>
<read_first>
- app/page.tsx
- components/CollectionToolbar.tsx
</read_first>
<action>
Integrate the mode selection into `app/page.tsx`:
1. Use the `useAppMode` hook.
2. If `mode === null`, render `<ModeSelectionScreen />` instead of the main split layout.
3. Pass `isSimpleMode={mode === 'simple'}` to `useCollections(mode === 'simple')`.
4. In the `header-right` area, add a mode switcher (e.g., a simple button or select) that calls `switchMode` to toggle between Simple and Workspace.
5. Pass an `isSimpleMode` prop down to `CollectionToolbar` and `CollectionExplorer`.
6. In `CollectionToolbar.tsx`, conditionally hide the "Yeni Klasör" (New Folder) button if `isSimpleMode` is true.
