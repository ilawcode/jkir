# Phase 2: Diff Code Editor Representation - Plan 1

## Goal
Render the differences visually inside `.tsx` coding views using CodeMirror merge capabilities.

## Tasks

### 1. Install CodeMirror Merge Extension
<task>
<read_first>
- package.json
</read_first>
<action>
Modify package.json to include `"@codemirror/merge": "^6.x.x"` and run npm install, or just run `npm install @codemirror/merge`.
</action>
<acceptance_criteria>
- `grep -n "@codemirror/merge" package.json` returns > 0 lines.
</acceptance_criteria>
</task>

### 2. Configure SplitCodeView to accept compare target
<task>
<read_first>
- app/page.tsx
- components/SplitCodeView.tsx
</read_first>
<action>
1. In `app/page.tsx`, pass `compareTargetFile` along with a function `onCloseCompare={() => setCompareTargetId(null)}` down to `SplitCodeView`.
2. In `SplitCodeView.tsx`, update Props to include `compareTargetFile?: FileNode` and `onCloseCompare?: () => void`. 
</action>
<acceptance_criteria>
- `grep -n "compareTargetFile" components/SplitCodeView.tsx` returns > 0 lines.
- `grep -n "onCloseCompare" components/SplitCodeView.tsx` returns > 0 lines.
</acceptance_criteria>
</task>

### 3. Implement Visual Merge Editor in CodeView
<task>
<read_first>
- components/CodeView.tsx
- components/SplitCodeView.tsx
</read_first>
<action>
1. Update `CodeView.tsx` to accept a new prop `compareContent?: string`.
2. If `compareContent` is provided, instead of rendering a standard `EditorView`, it should use `@codemirror/merge`'s `MergeView`. The currently active file should be `a` (left side) and `compareContent` should be `b` (right side) to highlight the differences efficiently.
3. Apply standard styling to `.cm-mergeView` to clearly annotate added vs deleted chunks.
4. Inside `SplitCodeView.tsx`, if `compareTargetFile` is defined, pass `compareTargetFile.content` into `CodeView` as `compareContent`. Also render a UI button above the editor "Karşılaştırmayı Kapat" (Close Compare) that triggers `onCloseCompare`.
</action>
<acceptance_criteria>
- `grep -n "MergeView" components/CodeView.tsx` returns > 0 lines.
- `grep -n "compareContent" components/CodeView.tsx` returns > 0 lines.
</acceptance_criteria>
</task>

## Verification
<must_haves>
- The Code Editor splits to show modifications, additions, and deletions between two files when compared.
- Merged difference styles visually map changes in a distinct and understandable manner.
- Users can easily dismiss the compare mode and return to standard code editing.
- Compare view relies exclusively on the Code Editor tab and disables formatting/tree views during diffs.
</must_haves>
